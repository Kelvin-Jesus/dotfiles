# Silakka54 keyboard

`kj-custom-silakka54.vil` is the Vial export for the Silakka54 keymap.

Restore flow:

1. Connect the Silakka54.
2. Open Vial or a compatible VIA/Vial configurator.
3. Import `assets/keyboards/silakka54/kj-custom-silakka54.vil`.
4. Review the keymap before writing it to the keyboard.

This is intentionally not applied by `install.sh`: flashing/importing keyboard
configuration depends on the keyboard being connected and should stay an
explicit hardware action.
