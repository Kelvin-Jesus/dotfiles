# LazyVim

Configuração baseada no starter oficial do LazyVim.

Customizações preservadas da configuração AstroNvim anterior:

- Catppuccin Mocha;
- números absoluto e relativo;
- `signcolumn` sempre visível e linhas sem wrap;
- `Ctrl-S` para salvar;
- `Alt-J` e `Alt-K` para mover uma seleção;
- suporte a Gleam;
- ferramentas Mason;
- formatação automática ao salvar.
